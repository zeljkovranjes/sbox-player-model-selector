=====================

This addon provides the Custom Player Model tab, a window for wearing any rigged
humanoid model in s&box's [Sandbox].

[Sandbox]: https://sbox.game/facepunch/sandbox

<br>

## Install

Requires Sandbox (`facepunch.sandbox`).

1. In Sandbox, open the spawn menu's **Entities** tab.
2. Search for **Player Model Selector**
   (`notpointless.chomnr_player_model_selector`) and spawn it.
3. Hold **C** and open the **Custom Player Model** tab.

From source: open `player-model-selector.sbproj` in the s&box editor, press Play
and spawn it from **Entities > World**.

<br>

## Features

- **Models**: any rigged humanoid from the game, sbox.game or a mounted game
- **Customize**: skin, colors, finishes, body shape, body groups and morphs
- **Items**: up to 8 hats, glasses and clothes on any model
- **Effects**: 20 presets, sliders, layers, triggers and keys
- **Shapes and stickers**: draw, write, erase; layered stickers with finishes
- **Weapons**: finishes, skins, stickers, props, parts and effects, per weapon
- **Scripting**: a small language with a code editor and a live reference
- **Workshops**: share, rate, use and fork looks, effects, shapes and designs
- **Server settings**: the host decides what is allowed and how much shows
