# Changelog

## 2026-10-25
Title: Customize, View Models, Armature and Server
### Added
# Models
Favorites - right-click a model or click its heart to keep it in the Favorites group, the first tile of the grid on both the Models and View Model pages, there even before the first favorite; a favorite the server no longer offers is hidden, not lost
Groups - models are grouped into Official, Facepunch, Other and one group per mounted game, each shown as a tile (a game with its own logo); click one to see its models twenty at a time, with Previous and Next
Facepunch models - a second search finds Facepunch's own characters on sbox.game
Human models - sbox.game's Human category (over 300 models) is listed too, under Other, less the hands, arms, clothing and citizens and the models with too few bones for a body
More models - every sbox.game search lists its next page when you reach the end of Other or Facepunch, so a long category isn't fetched all at once
Not bodies - sbox.game packages tagged hand, hands, arm, arms, clothing or citizen aren't offered as bodies, and a model sbox.game says has fewer than 15 bones, or is under 48 units across (a hat, a shirt, hair rigged to the citizen), leaves the grid at once, without being downloaded; mounted models under that size are refused too
No materials - an sbox.game package published without its materials (only the error checkerboard to show) is refused when picked and leaves the grid
Checked as you look - a model is checked only while its group is open (or it matches the search), several at a time, so a game or search with thousands of models never loads them all at once; with the menu closed, the first page of each group is checked ahead from the moment the selector is in the world, so the menu opens on models already checked
Download on pick - an sbox.game model downloads only when you pick it, never while you browse or hover: its tile shows a download icon until then, and while it downloads the tile lightens from left to right (an estimate from the package's size and earlier downloads, as s&box doesn't report a download's progress); picking another model meanwhile drops the download, so sbox.game not answering never leaves the grid stuck on it
Caching - searches are kept for an hour and every check for as long as its package isn't updated, so starting or joining again doesn't ask sbox.game again
Mounts - characters from mounted games are offered once they pass the same check, a group per game; they are looked for in folders named like player, humans, characters, heroes, npc, actors and peds, and a game whose folders say nothing offers all its models, characters by name first, so any mount works without setting anything up; a game mounted while you play joins them within 5 seconds
Model folders - the folder button next to the search box lists each mounted game's model folders with how many models each holds, each game folding away like the grid's groups; turn a folder on and its models come first in its game's group, each checked as it is shown
Mounted textures - a mounted model whose own shader doesn't load (compiled for an older s&box, or not found) shows its textures on the standard shader instead of the error material: on its body, in the preview, on its tile (drawn once and kept on your machine) and as first-person arms, on Windows and Linux alike
Offline notice - when sbox.game or the Workshop can't be reached, the grid says so the way the Effects page does
Search - type in the box above the grid to find a model by name; every match shows, folded groups or not
# Customize
Skins - pick one of the model's skins from a dropdown, where it has more than one
Saved looks - save what you made under a name and put it on again later, per model
Part colors - tint single parts of a model (jacket, hair, eyes) as well as the whole model
Body Shape - height, head, body, arm, hand, leg and foot sliders that work on any model, morphs or not
Body groups - choose heads, capes and accessories by name, or hide an accessory (a hat, a weapon, a pet); hovering a choice points it out on the preview; the body itself (head, chest, legs, arms, hands, feet) can never be hidden, so nobody turns invisible
Body group colors - each body group's color is right under its choices, for the choice picked
Apply and Revert - changes show in the preview first and reach everyone when you press Apply
Advanced editor - the Advanced editor button on the Customize page opens a window over the whole screen with your model in the middle, the options down the right, and Share mine, Copy code, Revert, Apply and Close along the bottom; your character stands still while it is open
Camera - the Advanced editor's view moves the way Blender's does: middle-drag orbits, Shift+middle pans, Ctrl+middle or the wheel zooms (Alt+left orbits without a middle button), numpad 1, 3 and 7 look from the front, right and top (Ctrl for the other side), 2, 4, 6 and 8 step around, Home frames the body and numpad . the selected item; Walk (Shift+`) flies with WASD, Q and E; the model turns in the room left of the options
Gizmo - click an item in the Advanced editor to select it and move, turn and size it with Blender's gizmo (arrows, rings and boxes, from the Move, Rotate, Scale or Transform tool) or Blender's keys: G, R and S, then X, Y or Z for an axis (Shift for a plane), a typed number, Ctrl to snap and Shift for precision, left click or Enter to keep and right click or Esc to cancel; Alt+G, Alt+R and Alt+S clear, Shift+D duplicates, Delete removes, and Ctrl+Z and Ctrl+Shift+Z undo and redo; every move stays within the item's caps
Animation graph - the Advanced editor says which animation graph system moves your model, "AnimGraph1 (legacy)" or "Using AnimGraph2" on s&box builds that have AnimGraph2
Styles - save what you made as a style in the Advanced editor, Switch to one to edit it, and Save changes to keep them; styles are yours alone, and editing one never changes what you published from it
Material finishes - give the whole model or single parts one of 8 stock finishes (gold, silver, chrome, copper, bronze, gloss, clay, matte black), in the Advanced editor; they take colors, and they work on mounted models, which colors of single parts don't
Hide parts - hide a single part of a model from the Finish list in the Advanced editor, such as a dress that isn't a body group; skin and body parts can't be hidden, and neither can the last part showing, on anyone's screen
Accessories - wear up to 8 cosmetics on any model, in the Advanced editor: every stock item and everything on the Workshop (1,500+), picked from a list of categories down the side, with pictures and a search; glasses, hats, hair and the like are pinned to a joint and can be moved, turned and sized, clothes bend with the body, and each has its own colors, finish, body groups and morphs; an item stays under half the model's height and within a quarter of it from its joint, on everyone's screen, and other players download the Workshop items you wear, which count towards your download limit on the server
Shared looks - Share mine, under the Customize options, publishes your look for a model (skin, colors, finishes, body groups, morphs, body shape, items) where every player of the selector can find it; the Workshop button beside Reset everything opens the looks players shared, rated and a page at a time like shared armatures, where Use puts one on the preview and Apply wears it; Copy code puts it on the clipboard as one line of text
Share details - sharing a look or an armature asks what to call it (up to 32 characters) and for a description (optional, up to 128); the Workshop lists each by its name with its author's Steam avatar and name as they are now, and the info button beside one shows its description, its author and everything else they shared
Publishing - what you publish stays as it was published: to share changes, publish again as a new one (5 at once per model); your own can be taken down from the info button
Workshop status - a red bar reads "Facepunch Workshop is currently unresponsive" while Facepunch's service isn't answering, and goes away by itself when it is back (asked every 30 seconds)
# Effects
Effects - the Effects tab beside Customize puts effects on your model from 20 presets (glowing eyes, fire hands, sparkle halo, holy aura, dark aura, hearts, snow cloud, rain cloud, electric body, magic orbs, flame head, lantern hand, speed trail, sword slash, blade trail, confetti burst, rainbow, bullet tracer, muzzle flash and impact sparks), each tile moving as its effect does; the preview shows them at once and Apply wears them, up to 8 at a time; auras, clouds, hearts and sparks round the body stay on you as you walk and run, still drifting as they rise
Effect sliders - Color, Size, Amount and Speed change the selected effect all at once: Color turns its colors round the color wheel, Size and Speed go from half to twice, Amount from a quarter to four times; switch an effect off and on, or remove it, in the list of effects you wear
Effect keys - give an effect a key (letters, digits, F1 to F12 or the side mouse buttons, suggested as you type, with the key's picture beside it) and choose what it does: show the effect for 10 seconds, switch it on and off, or show it while held, for everyone, fading in and out over half a second; a player who joins meanwhile sees it for the time it has left; starting an effect with a key works once every 2 minutes for each player, whichever effect it is for, and the host holds everyone to that (and every machine refuses a start inside it), while switching one off or letting go is always free
Clan tag colors - Rainbow colors its sprites one by one with World at War's scrolling clan tag colors (rain); the selected effect's colors can be changed, added to (any number), removed (Remove, down to one) or put back to the game's five under its sliders
What you see - Effects quality (High, Normal, Low or Off) shows less of everyone's effects on your screen, never more than the host allows, and any other player's can be hidden; both are kept on your machine
Near the camera - effects fade as they come near your camera (whole from 60 units away, gone by 20; each sprite on its own, lights and trails by where they are), so a cloud over your head in third person or another player's aura in your face never covers your view; your first-person weapon's effects stay whole
Any model - effects are made on the citizen and worn in proportion on any model, from its eyes (each eye or between them), the top of its head (however high it reaches over its head bone), head, neck, chest, hips, hands or feet; a joint the model doesn't mark is stood in for, so an effect always shows
Drawn on your machine - effects' pictures (glow, spark, flame, smoke, sparkle, heart, snowflake, droplet) are drawn from lines on every machine, so effects add nothing to download or publish; every picture fades to nothing before its edge, so big glows over each other (Holy aura) stay round in the game's light instead of showing squares
Citizen effects - the default citizen wears effects too, without picking a model: on the Effects tab, in the preview and for everyone, kept for the citizen like a model's look
Effect layers - Edit in Advanced editor, on the Effects tab, opens the Advanced editor's Effects tab on the selected effect: add sprites, a light or a trail (up to 8 layers an effect, 32 a look), copy, reorder, switch off and remove its layers, with each layer's main settings showing and the rest under More
New effect - the first tile on the Effects tab, and New effect in the Advanced editor's Effects tab, start an effect of your own from scratch ("My effect 1", from the chest, with one layer of sparkles to build on) and open it in the Advanced editor; it counts towards the budget and saves to My effects and shares like any other
Comes from - an effect comes from a joint, an item worn (it follows the item as it moves, whatever its place in the list) or the tip of the weapon held; Keep it where it is keeps it in place when it moves to another, Forward, Left and Up nudge it (up to 24 units each way), and while the item is off or nothing is held it shows on the joint it was on
As you move - each layer of sprites, beside Comes from, either moves with the body or leaves a trail behind, and Drag (0 to 1) lets sprites that move with it lag a little; the presets pick what fits: Dark aura's mist, Holy aura, the clouds, the halo and the orbs stay on you, falling snow lags a little and rain and Speed trail's sparks trail
Shapes - sprites come from a point, a ball, a ring, all around the body, a box, a cone, a line (across, or from one joint to another) or one of 40 standard shapes (circles, polygons, stars, crosses, hearts, lines, waves, spirals and solids like a sphere, a cube or a torus), along its outline or all over it, and each sprite can look like any of the shapes; the shapes are worked out on your machine, so nothing is downloaded
Rhythm and When - a layer can pulse, flicker, go through every color, turn round its place (circling it when set off to the side) or jiggle, and show always, while you move, stand, are in the air, crouch or hold a weapon, or for a moment when you jump, land, get hurt, start or stop moving, crouch, stand up, shoot or swing, hit something hard, die (on your ragdoll), spawn again or take a step (a layer on a foot steps with that foot alone), with a burst of up to 100 sprites and showing for up to 5 seconds; every client works these out from what it already sees of you, and each counts at most 10 times a second (shots 20)
Trails - a layer can be a trail behind its place, from its color and width to its end color and width, lasting up to 5 seconds, and showing only as much as its place moves (a sword's swing, a runner's feet)
Mixed colors - a layer's sprites can each take one of its colors in turn and keep it, like confetti
Guides - Guides, on the Effects tab, explains what an effect, a layer, an anchor, Comes from and Looks like, Rhythm, When, keys, shapes, stickers (layers like an emblem, with eraser cut-outs and finishes), the Workshop (Use and Fork), color cycles, weapon designs, scripts, parameters and the budget are, and how to build an effect from layers, put one on a hat or a weapon, show a layer on a jump or a key, set up a sword slash, customize your weapon, add bullet tracers, write your first expressions, remix from the Workshop, draw your own shape (with the eraser) and make a sticker, each with a short clip recorded in the game (25 clips, 3.9 MB)
Sums in number boxes - type a sum like 2*3+1 or (10-4)/4 in the number boxes of the Advanced editor's Effects tab: it is worked out when you press Enter or click away and held to the box's range, and anything that isn't a sum puts the number back
Drawn shapes on bodies - a drawn shape is drawn on your machine once (128 px; a sticker 256 px, a layer at a time), a millisecond or so a frame as players join, and shared by everyone wearing it, so a hundred players with the same sticker make one picture; a sticker's moving layers are put together again 15 times a second while it is near, within half a millisecond a frame; what is kept stays within 16 MB (256 shapes or 64 stickers), and past that the furthest players show a plain circle until a nearer one is let go; a server with no screen draws none
Drafts - Save draft keeps unfinished work on your machine to come back to: an effect (in the Advanced editor or under its sliders), a script (Keep as draft in the code editor: its text exactly as it is, errors and all), a shape or sticker (in the creator) or a weapon's design (in weapon mode); drafts show with a pencil in the top left corner in My effects (a script's with a code sign, opening in the code editor where you left off), My shapes and the weapon's Drafts, reopen as they were left (the layers selected, the tools picked), and Finish (Save, for a script) makes one an item like any other; until then a draft shows in the preview but isn't worn, shared or published, and Variations leave it alone; closing the Advanced editor with changes not applied asks Apply, Keep as draft, Discard or Cancel, and leaving the creator or the code editor with changes asks Save, Keep as draft, Discard or Cancel; up to 50 of each kind, newest first with how long ago each was edited, the oldest asked about before it is dropped, kept in the game's data folder rather than its cookies
More right-click menus - right-click a layer (Copy, Paste, Duplicate, Move up, Move down, Switch on or off, Delete), an effect you wear (Edit, Duplicate, Save to My effects, Save draft, Remove), a tile of My effects or My shapes or a draft (Open, Rename, Duplicate, Delete, Publish, Copy code), a sticker's layer (Duplicate, Delete, To front, To back, Lock, Hide, Group) or a Workshop row (Use, Fork, Details, Hide author, and Block for the host); each is also a button or a key, and a tile's or row's menu button opens the same menu; Shift+F10 or the menu key opens the menu of whatever the mouse is over, anywhere one exists (the weapon's parts, props and stickers on the preview too), or else of what is selected (the layer, the sticker's layers, the effect you wear, the weapon's prop or sticker)
Undo and redo - the arrows on the Effects tab and in the Advanced editor's Effects tab step back and forward through your changes to effects, 50 steps (a slider dragged is one step)
Several layers at once - Ctrl+click or Shift+click layers in the Advanced editor to choose more than one: a change goes to all of them, and only what they all have shows
My effects - save the selected effect under a name (Save to My effects, under its sliders) and put it on again from its tile on the Effects tab; up to 50, kept on your machine, each deleted from its tile's corner
Surprise me - the tile after the presets makes an effect of one to three parts of the presets and My effects, each on the joint it came from, its colors turned at random, within what this server's budget has left (its sprites thinned to fit)
Variations - Variations, under the selected effect's sliders, offers four copies of it with its colors turned, its size, amount and speed nudged and now and then a layer's rhythm or picture swapped; click one to use it, or More like it for four more
Shape creator - Draw a new shape, at the end of a layer's shape and Looks like lists in the Advanced editor, opens the creator in Shape mode: draw with the mouse (each stroke smoothed and simplified), as lines or filled, write text (the Hershey font, so it is the same on every machine), add a standard shape or one of yours, then mirror, flip, turn, size and fit it, up to 500 points a shape, with undo and redo a stroke at a time; Use as Comes from sends sprites out along it, Use as Looks like makes each sprite it, standing upright so its text reads
Eraser - the creator's eraser cuts away whatever of a shape is under it, fill, lines and text alike, as wide as its slider says ([ and ] while the canvas has the focus; a circle at the cursor shows it), undone a stroke at a time; on a sticker's drawn layer it cuts that layer alone, the layer's outline following the new edge, and as an eraser layer it cuts every layer below it; sprites coming from a shape skip what was erased, and the eraser's points count towards the shape's
Stickers - Sticker mode in the creator makes a sticker of up to 32 layers, like a game's emblem editor: each a standard shape, one of your shapes or stickers, one from the Workshop, a drawing or text, moved, turned, sized each way and flipped by its handles on the canvas (the wheel sizes what is selected, Shift+wheel turns it, the arrows nudge it) or by numbers, with its own color, opacity, outline and moving color (Rainbow, the clan tag Rain, Cycle and Scanner with their colors, or Pulse, the layers moving the same way taking turns like a clan tag's letters); layers are put in order, duplicated, deleted, hidden, locked and grouped, several moved, sized and turned together, snapping to a grid and onto the middle (centre guides show), mirrored for a symmetric sticker, with undo and redo; a sticker's drawn layers have 2,000 points; each sprite of a sticker covers what is behind it, and a sticker made before layers opens as a sticker of one
My shapes - shapes and stickers are kept by name (up to 50, on your machine), opened in the creator again to change and picked in a layer's lists and a weapon's stickers; right-click a tile, or its menu button, to open, rename, duplicate, delete, publish or copy its code; a look carries each it uses once (up to 8 a look, with 4,000 points and 64 sticker layers in all), so everyone sees them with nothing to download, and a tampered look is clamped in well under a millisecond (500 points a shape, 32 layers and 2,000 points a sticker, the rest left out)
Effects Workshop - Workshop, on the Effects tab, lists the effects and single layers players shared, for any model: Top or New, a search box, filters by where it comes from, whole effect or layer, what it has and the #tags in its description, a moving picture of each drawn on your machine, ratings, Hide author, and details with the author's other shares; Use puts a copy on (a single layer joins the effect you selected), Fork opens a copy in the Advanced editor, and both credit the share ("Based on" its name and author), kept when you publish your own
Sharing effects - Share this effect, under the selected effect's sliders, and Share this layer in the Advanced editor (beside Save layer to My effects) publish it with a name (up to 32 characters) and a description (up to 128), carrying the drawn shapes it uses; the same effect is never published twice (an unchanged fork included), each player has up to 20 published at once, a share bigger than the Workshop's 64 KB record is refused, and one read back past it is passed over
Shapes and Stickers - the Effects tab has three categories, Effects, Shapes and Stickers: Shapes lists the 40 standard shapes (click one to make a shape of your own from it), New shape and My shapes; Stickers lists New sticker and My stickers; each opens the creator, and drafts show among them
Shapes and stickers Workshop - the Workshop has the same three tabs, and Workshop shapes and Workshop stickers at the end of a layer's shape lists open the matching one: the shapes and stickers players made, with the same search, filters (stickers by how they move and how many layers), ratings and details; Use keeps one in My shapes or My stickers (from a layer's list it goes on the layer too, from a sticker's Add a layer it becomes a layer), Fork opens a copy in the creator, and Publish shape or Publish sticker in the creator publishes yours

Ground - an effect or a layer can come from the ground under the feet (Ground (under the feet), in Comes from and From joint): below the hips at the feet's height, turned the way the body faces however it leans, so a circle there lies under the player as they walk or run

# Weapons
Weapon designs - each weapon has a design of its own, kept by its world model so it shows on the same weapon in any game and worn on whichever weapon you hold, for everyone: a finish (the 8 stock finishes) and a tint, a skin painted over it from every side with no UVs needed (stripes, camo, checker, gradient, carbon or a repeated shape, which can scroll and spin) and colours moving over it (a rainbow flowing along it, World at War's Rain, Cycle and Scanner in bands along it, a pulse, a glow, a sheen sweeping over it or a palette going round, each with its speed and colours), stock props on it, stickers pressed onto its surface (pictures, standard shapes or your drawn shapes, in one colour or a moving one) and effects coming from it; under a skin or stickers the weapon keeps its own surface (its colour, bumps, roughness, metalness, shadows and glow, read as its own material reads them) unless a finish takes its place, so a stickered gun is the gun as it was plus its stickers; only the weapon held is dressed, when it changes, and a hundred players with the same skin share its materials
Weapon mode - with a weapon in your hands the Advanced editor's preview holds it too: point at it and it glows softly (fading in and out), double-click it to design it (the view turns to its side and the heading reads Editing: and the weapon's name), and double-click the player or Back to player to go back; the weapon's panel has its finish, tint, skin and moving colours, stickers, props (the 88 stock props, with a search), parts and effects, with undo and redo, the gizmo moves props and stickers as it moves items, and pointing at a part outlines it
Right-click menus - right-click a weapon's part for Replace with prop, Attach to this part and Hide part, or a prop or sticker for Edit, Duplicate, First-person nudge and Remove; every one of them is on the weapon's panel too; Esc or a click anywhere else closes a menu
Sticker finishes - a sticker is printed on paper, holo, foil, glitter, gold or lenticular (Printed on, in the creator's Sticker mode; a weapon's sticker can take another): on a weapon, stickers are drawn by the weapon's own surface, flush on it and lit as the gun is, pressed onto the first surface they meet from the side they are pressed from (never what lies behind it, like the far side or a cable), wrapping over a curve at their own size rather than stretching, fading off faces that turn away, never on a hand holding it, in third and first person; holo's rainbow film shifts and glitter twinkles as the weapon or camera turns, foil and gold shine, and a lenticular sticker swaps between two looks with the angle (each layer shows in the first look, the second or both); each weapon sticker has a Scrape slider (0 new to 1 worn away in patches, the same on every machine) and an optional white die-cut border; tiles shimmer while you point at them, sprites show a finish over time (holo going round the colors, foil and gold shining, glitter twinkling, and a lenticular sticker's sprites showing both its looks, swapping as the camera goes round you, as time passes and in bands across the layer), and the Workshop's stickers filter by finish
Weapon Workshop - Share this design publishes a weapon's design for that weapon (with a picture of it drawn on your machine, its weapon dressed), and the Workshop button in weapon mode, which counts them (Workshop (3)), lists the designs shared for the weapon you hold, with Top and New, search, ratings, Hide author, Use and Fork (an editable copy on your weapon, credited), and All weapons to see every weapon's
Weapon parts - a design can hide a weapon's parts (its magazine, a rail, the sights: whatever its model lets show or hide), put a prop on a part or have a prop take a part's place (as large as the part, or 16 units, whichever is larger), and in first person a prop on a part follows it through every animation, like a can for a magazine coming out and going back in on a reload
First-person weapon - your weapon in first person wears its design too: its skin always, and its props, stickers and the effects that come from it (from its muzzle, half size so none covers your view) while Show weapon effects in first person is on, on the View Model page beside the arms switch; props and stickers are mapped from the world model onto the first-person one by their muzzles and sizes, each prop can be nudged there, and nothing shows twice; it stays dressed, unseen, in third person, and a look's designs have their skins made and props loaded as the look arrives, so switching view or weapon shows it dressed from the first frame; a weapon anyone draws, near or far, even with nothing in hand before, is dressed (skin, stickers, props and its effects) in the frame it first appears, the skin's shader is readied once before any weapon wears it, and what is made for weapons (materials, sticker meshes, prop models) is kept for the players nearest you first: past its caps the furthest players' go, then what was used longest ago
Weapon events - a layer can show when you reload, draw a weapon or put it away, or when your shot or swing hits something; each shot runs from the weapon's muzzle along where you aim to what it hits (every machine works it out with one trace that passes through the shooter, nothing more is sent, and none for players far away or out of view; a swing reaches 72 units), and a layer can come from along the shot or show where it hit; each counts at most 10 times a second (shots 20)
Weapon presets - Bullet tracer (a streak from the muzzle to where each shot hits, gone in a blink), Muzzle flash (a burst of fire and light at the muzzle) and Impact sparks (sparks and a puff of smoke off what a shot or swing hits) work on any weapon, no setup needed
Sword slash - the classic slash: with each swing a crescent appears in front of you, lying along the swing (worked out from where you aim and how the weapon's tip moves) and sweeping round with it, bright at its front and fading to nothing at its tail, gone in a quarter of a second; the trail on the weapon's tip it was before is Blade trail; a layer can look like a slash of any reach and thickness, lie along the swing and turn as it lives
Weapon switches - the Server page has Players can customize weapons, Weapon props and Weapon effects: off, players' weapons show as they come, or without the props or effects they gave them, and nothing is deleted (it all comes back when turned on); Mute and a player's own Hide cover weapon designs too
# Scripting
Scripts in looks - an effect written as a script, on your body or on a weapon's design, carries its script (minified) in your look, and every player's machine builds the effect again from it, so others see what the script makes, with the options you chose; a script is held to 16 KB (32 KB for a look's together, its weapons' included, the body's first) before anything reads it, compiled once per look change and kept by its text (a hundred players with one script compile it once), and each player's new scripts compile at most 2 a second on each machine (8 at once); one that doesn't compile shows what it made when it was saved
Scripts that run - an effect's script runs on every player's machine while the effect shows: OnUpdate each frame, its events (OnSpawn, OnKey, jumping, landing, getting hurt, dying, spawning again, each footstep, crouching, starting or stopping, hitting something hard, shooting or swinging, reloading, drawing a weapon or putting it away, a shot or swing hitting, a kill) as each happens, at most 10 times a second each (shots 20), and each layer's particle function for every sprite, moving, colouring, fading, turning and sizing it; one player's scripts run at most 60,000 instructions a frame and everyone's 600,000, a body out of view or too far to show effects runs none, and no sprite is ever drawn bigger than 128 units, whatever a script asks
Pictures - Layer.Pictures gives a layer's sprites up to 16 pictures (stock pictures, shapes, text or your own shapes and stickers), one each, in turn as they appear or as the particle function picks with p.Frame: glyphs of digital rain, cards, letters; each picture is drawn by a renderer of its own, so they still batch with every other sprite
Kept sprites - Layer.Keep holds up to 100 sprites out all the time, each with its own p.Index from 0, spread evenly in that order along where the layer comes from, their life looping every Lifetime: formations a particle function moves (runes round a ring, orbs following a hand)
Beams - Beam() draws a ribbon through up to 64 points kept along where the layer comes from (a line between the hands, a ring), its colour and width going from start to end along it, each point moved, coloured and sized by the layer's particle function (lightning that jitters, a helix that turns)
Ghosts - Ghost() leaves see-through copies of the body (or of the weapon held, or the item the effect comes from) where it was and posed as it was, fading over the layer's lifetime: afterimages, up to 30 a second and 8 out at once
Sprites that lie - Layer.Align lays a layer's sprites flat on the ground (turned the way the body faces), along the last swing, facing the way the layer faces, or facing out from its middle like tiles on a ball, in place of facing the camera; p.Rotation turns each in its plane
Weapon fields in scripts - a script's layer can look like a slash of any reach and thickness (Picture.Slash, SlashArc, SlashThickness), lie along the swing (Align.Swing) and turn as it lives (Sweep), come from along the shot (ComesFrom.Shot) or show where it hit (AtHit), lag a little behind the body as it follows it (Drag), and show on reloading, drawing a weapon, putting it away, a hit, dying, spawning again and each footstep (When.OnReload and the rest, and OnReload() and the rest)
Presets are scripts - every stock effect (the weapon presets too), the colour modes (Rain, Cycle, Scanner, Mixed) and rhythms (Pulse, Flicker, Rainbow, Spin, Jiggle) layers use, the ways a sticker's colour moves (on a body, a weapon or a tile in the lists, and each layer of a sticker made of layers), and a weapon skin's moving colours (Rainbow, Rain, Cycle, Scanner, Pulse, Glow, Shimmer, Palette) and its pattern's scroll and spin (worked out once a frame for each different skin, however many players wear it, into a small table the skin's shader reads, looking as they did) are commented scripts in the effect language, built from them on every machine and looking as they did (a scanner sticker on a weapon given three colours or more now sweeps its first over its second, as everywhere else); a preset you put on carries its script (each well under 4 KB, so eight fit a look)
Code editor - Edit as code, on the Effects tab and in the Advanced editor, opens any effect (the presets too) as its script in a code editor: line numbers, VS Code's colours (Dark+ by default, Light+ with the theme button, kept on your machine), completion as you type (members, your own names, keys with their pictures, shapes and stickers with theirs), signature help in a call, docs on hover once the mouse rests on a word (staying while you move onto them, half a second after you leave both; More… opens the reference), a swatch before each colour (click it to pick another; the code keeps its form), a key's picture before each key, the bracket or block matching the caret, find and replace (match case, whole word, "3 of 12"), go to line, Ctrl+/ comments, Tab and Shift+Tab indent, Enter keeps the indent, brackets and quotes close themselves, Format; errors are underlined and counted (the list under the status bar), never popped up, and not while you are still typing the word
Auto-apply and Save - with Auto-apply on (the default, kept on your machine) the preview follows the code a moment after you stop typing, the last good version showing while it has an error; off, nothing changes until Save; Save (Ctrl+S) puts it on the effect and wears it for everyone, and the status bar shows its size ("3.2 KB of 16 KB") and where the caret is
Code window - drag the code editor by its title, size it from any edge or corner (down to 380 by 240), maximize it (the button or a double-click on the title); where it was, its theme, Auto-apply and find's Match case and Whole word are kept on your machine, and it opens whole on screen even at a smaller resolution; closing it with changes asks to Save, Discard, Keep as draft or Cancel
Code preview - the eye button in the code editor's toolbar shows your own character beside the code (the model you wear, as you made it, holding the weapon you hold) wearing the effect, weapon design, skin or sticker as you write it, with its test bar under it; it takes about two fifths of the window (never under 200 wide), the code takes the whole window while it is off, and on or off is kept on your machine (on at first)
Code and layers in step - with the Advanced editor open, every good build updates its layers and fields, and a change there is written into the code in place (the caret stays, undo works); a field the code works out (a loop, a function, a parameter) is put back with why and its line; the caret in a layer's lines selects that layer, and selecting a layer puts the caret on its lines
Weapon designs as code - Edit as code in weapon mode opens the weapon's whole design as a script: its finish and tint (Weapon), its skin (Skin: pattern, colours, scroll and spin, moving colours), and the stickers, props, hidden parts and effects put on it (Weapon.AddSticker, AddProp, HidePart, AddEffect), with completion for each field and for the held weapon's part names; every good build is put on the design, a change on the weapon's panel is written into the code in place, and the caret in a sticker's, prop's or effect's lines selects it on the panel (selecting one there selects its lines); a design with a script carries it (minified, 16 KB at most, within the look's 32 KB) and every machine builds it again, held to the panel's caps (8 stickers, 8 props of 16 units, 16 hidden parts, 4 effects); the scripting reference has a Weapon page with live examples (Rainbow flowing skin, Gold with a holo sticker, Magazine replaced by a can)
Skin scripts - write a weapon skin's moving colour yourself: Write your own, under Moving color in weapon mode, opens the colour picked as a script in the code editor (Edit script opens yours again, Stock lets it go), and the weapon in the preview follows as you type; the skin keeps it (16 KB at most, counted with the look's 32 KB of scripts), every machine runs it like the stock ones, once a frame for each different skin within the same budget, and where scripts are off or it doesn't compile the colour picked moves the weapon; the reference has a Weapon skins page with a live example (a heat haze)
Scripting reference - the ? button opens every name a script can use, with a search, each with a live example: change it and its preview (on the model you are wearing or editing, as you made it, with its own test bar) or its result follows, Reset example puts it back, and Copy into my effect puts it in your script; first pages say what a script is, how expressions work and what parameters are; it opens where you left it, and again with the code editor when you left it open
Parameters - an effect's script's options ([Parameter]) show under its four sliders on the Effects tab and with it in the Advanced editor, grouped and folding by group, each as its type says: a slider with a box for sums, a check mark, a colour, a palette to add to and take from, text, a shape or picture (the stock ones, or your own shapes and stickers from My shapes, Workshop ones you used among them, carried in your look so everyone sees them), a key with its picture, a list of choices or three numbers; a value chosen is kept with the effect (held to its range on every machine, gone when the script no longer has it), Reset puts the script's own back and Save as default writes it into the script
Stickers in scripts - a shape with layers (shape.AddLayer, or Shapes.New( "name" ).AddLayer in an effect) is a sticker of them, each layer placed, turned, sized, flipped, coloured, outlined and moving as it says, erasers (Eraser) cutting the layers below and a lenticular sticker's two looks (Side), mirrored (shape.Mirror) and printed on a finish (shape.Finish); an effect's sprites show it in its colours, and your own stickers taken by name (Stickers.Mine, Emblems.Mine) keep their layers and finish; a sticker can carry a sticker script of its own (16 KB at most, counted with the look's scripts) that colours each of its layers as it shows (i the layer, origin its place), on sprites, weapons and tiles alike, and fades, sizes, turns or moves each sprite showing it (alpha, size, rotation, offset), within a budget all sprites share each frame; where scripts are off its layers keep their own colours; in the creator's Sticker mode, Edit as code opens the sticker being made as a script (its layers, finish and mirror) beside it: every good build shows in the sticker editor (one step to undo), the editor's changes write the code again while it is the code the editor writes (code of your own, like a loop, is kept and the change put back, saying why), and Animate with code writes the sticker's own script, with completion, hover help and the reference as for effects
Faded shapes - a shape a script fades (Shape.Fade) is drawn fading round its middle, from nothing at its tail to all of it at its front, on bodies and in the lists alike: a slash's crescent with a bright front and no tail
Set by script - in the Advanced editor a scripted layer lists the fields its code works out (or a parameter gives, or a function changes while it runs), each with its line: click one to open the code there

# Server
Server page - the host decides which models players can wear: models from sbox.game, from mounted games, or neither; the default citizen and the game's own models always stay

Package vetting - the host checks every sbox.game pick against the same rules (a model, not tagged as a hand, arm, clothing or the citizen, enough bones) before anyone sees it, so a changed client can't wear what the window leaves out
Download limit - everyone here downloads each sbox.game model a player puts on, so each player other than the host brings in 3 new ones every 5 minutes, both set on the Server page (up to 50, over up to 60 minutes); every machine starts downloading a model as soon as the host takes it, so it is there when its player comes into view
